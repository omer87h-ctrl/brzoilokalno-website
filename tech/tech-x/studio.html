NAPRAVI PRAVU WEB STRANICU.

Uredi HTML, CSS i JavaScript. Pokreni interaktivni pregled, prilagodi prikaz za telefon i preuzmi kompletnu stranicu kao jednu .html datoteku. Projekat možeš sačuvati na svom uređaju ili izvesti u JSON formatu za nastavak rada.

Ovo je stvarni editor, ne slika editora. Pregled izvršava tvoj JavaScript u izoliranom okviru s ograničenim pristupom mreži. Gotova preuzeta HTML stranica može izvršavati tvoj kod bez tih ograničenja, zato koristi samo kod kojem vjeruješ. Stranice se ovdje ne objavljuju na javnom internetu.

Kod se izvršava samo kada pokreneš pregled. Projekt nije objavljen.
